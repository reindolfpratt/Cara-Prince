# Cara Prince — Strategic Consulting & Programme Leadership

Official website and digital platform for **Cara Prince**, Senior Non-Profit Leader & Executive Consultant based in London, United Kingdom.

> *"Empowering purpose-driven organisations with community clarity, structural resilience, and sustainable growth."*

---

## 🏛️ Overview

This platform showcases Cara Prince's consulting services, proven track record, leadership story, and client enquiry workflow. Designed with a bespoke, high-fashion editorial aesthetic inspired by minimalist British typography, soft watercolour brand tones, and clean information architecture.

### Key Pages:
- **`index.html`** — Executive Overview, Core Principles, Key Impact Metrics, and Featured Engagements.
- **`story.html`** — Professional Narrative, The "Why", Values, and Methodological Approach.
- **`experience.html`** — Career Trajectory, Past Positions, Proven Impact, and Industry Sectors.
- **`services.html`** — Comprehensive Service Scopes, Deliverables, and Transparent Hourly Rates.
- **`contact.html`** — Proposal Request and Direct Consultation Enquiry Portal.

---

## 🎨 Visual Identity & Tech Stack

- **Design Tone**: Editorial elegance, high-fashion typographic hierarchy, and custom watercolour brand accents (`#8fb6d4` sky-blue and `#e8b7bc` blush rose).
- **Typography**: 
  - Serif: *Cormorant Garamond* (Editorial headlines & display quotes)
  - Sans-Serif: *Plus Jakarta Sans* (Clean, human geometric sans)
- **Frontend Architecture**:
  - Semantic HTML5 (with complete SEO meta tags, OpenGraph, and accessibility features)
  - Vanilla CSS3 (Custom properties design system, responsive flexbox & grid, backdrop filters)
  - Vanilla JavaScript (Dynamic London time clock, interactive proposal calculator, mobile drawer, smooth navigation)

---

## 🚀 Running Locally

No dependencies or build tools required. You can preview the website by opening any HTML file directly in any modern browser:

```bash
# Using Python's built-in HTTP server
python3 -m http.server 8000

# Or open directly in your browser
open index.html
```
